# Football match modeling
Bayesian and Bivariate Poisson models for football matches.

## Bivariate Poisson model
Bivariate Poisson model is recapitulated from "Analysis of sports data by using bivariate Poisson models".  
https://rss.onlinelibrary.wiley.com/doi/abs/10.1111/1467-9884.00366.  
Data is "2025-2026" England Prime League. From: football-data.co.uk.

In the following file is the EM algorithm, written in Python, for fitting the bivariate Poisson model and the observed likelihood as well as AIC.

https://www.tandfonline.com/doi/full/10.1080/02664760802684177.  
Data is "2025-2026" England Prime League. From: football-data.co.uk.
